# Dan Hamilton

*Real-time data engineer and founder working in web3, sports, and odds
data. Dreaming of a fully normalized and efficient data transit system.*

Co-founder & CTO at **[Kaz.markets](https://kaz.markets)** — a non-custodial
routing and settlement layer that aggregates decentralized venues on Solana
and executes at the best all-in price.

I build market-data systems. Before Kaz: real-time odds feeds aggregating
dozens of books, a public odds API for external customers, and the trading
infrastructure behind live sportsbook operations. Before that: data moving
through efficient networks.

## Things I work on

- **[kaz-markets](https://github.com/kaz-markets)** — routing engine, venue
  adapters, equivalence layer, quote engine
- **[openbook-data-standards](https://github.com/openbook-data-standards)** —
  open, vendor-neutral data contracts for markets:
  - **[OpenBook](https://github.com/openbook-data-standards/openbook)** — the
    standard: reference model, live wire, controlled vocabularies ·
    [site](https://openbook-data-standards.github.io/openbook/)
  - **[openbook-js](https://github.com/openbook-data-standards/openbook-js)** —
    JS client: stream or HTTP, cache the documents, bind to React
  - **[openbook-translate](https://github.com/openbook-data-standards/openbook-translate)** —
    vendor translate/reverse kernel
  - **[openbook-betting](https://github.com/openbook-data-standards/openbook-betting)** —
    betting profile: venue coverage and execution
  - **[openbook-starter](https://github.com/openbook-data-standards/openbook-starter)** —
    publisher starter kit (CLI + example)
  - **[OpenVenue](https://github.com/openbook-data-standards/openvenue)** —
    canonical market schema, equivalence layer, all-in quote contract for
    tokenized venues
