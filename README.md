# Dan Hamilton

Co-founder & CTO at **[Kaz.markets](https://kaz.markets)** — a non-custodial
routing and settlement layer that aggregates decentralized venues on Solana
and executes at the best all-in price.

I build market-data systems. Before Kaz: real-time odds feeds aggregating
dozens of books, a public odds API for external customers, and the trading
infrastructure behind live sportsbook operations. Before that: data moving
through efficient networks.
